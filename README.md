# Airline

Лабораторна робота №1 з ООП, варіант 9: «Авіакомпанія».

Консольний Java-додаток: ієрархія літаків, авіакомпанія, підрахунок
загальної місткості та вантажопідйомності, сортування за дальністю
польоту, пошук за діапазоном споживання палива.

Повний опис, запуск і формат даних буде додано на завершальному етапі.
